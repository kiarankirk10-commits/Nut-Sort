# Nut Sort

A personal, offline, ad-free nuts-and-bolts colour sorting game. **Created by Kiaran.** Funded by F. Roughan.

- Play on the Mac: `node tools/serve.js` → http://localhost:8080
- Install on iPhone: see [docs/INSTALL_IPHONE.md](docs/INSTALL_IPHONE.md)
- Tests: `npm test` · smoke test: `npm run smoke` · verify levels: `node tools/verify-all.js`
- Docs: [SPEC](docs/SPEC.md) · [DECISIONS](docs/DECISIONS.md) · [TUNING](docs/TUNING.md) · [PROGRESS](docs/PROGRESS.md) · [IDEAS](docs/IDEAS.md) · [LEVEL_STATS](docs/LEVEL_STATS.md)

Vanilla HTML/CSS/JS, zero runtime dependencies, no network calls at runtime. Poppins font © The Poppins Project Authors (SIL OFL, `app/fonts/OFL.txt`).
