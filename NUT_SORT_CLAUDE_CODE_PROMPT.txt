=== CORE RULES ===
- Board = bolts (stacks). Each bolt has capacity H (nuts high). Each colour has exactly H nuts ("nuts per colour" = bolt height for that board). Some bolts start empty (spares).
- Move: tap a source bolt -> its top run lifts and every legal destination bolt glows gold; tap destination to drop; tap source again or elsewhere to cancel. Legal destination = empty bolt OR bolt whose top nut is same colour, with room.
- GROUP MOVES (v2 rule 1): the whole contiguous top run of one colour moves together; moves as many as fit (min(run length, free slots)); player cannot choose fewer. Room for 3 & run of 2 -> both move; room for 1 -> one moves, rest stay. Animation: run lifts, glides, drops together with tiny stagger. A group move counts as 1 move.
- Win: every non-empty bolt full and single-coloured. Finished bolt gets gold check + gold pulse.
- MYSTERY NUTS (v2 rule 2): hidden nuts render grey with "?" . A hidden nut reveals its colour (180ms grey->colour) when the nut directly above it leaves (i.e. it becomes the top). Only the VISIBLE top run moves as a group; a nut revealed by a move never joins that same move; hidden nuts never join a group. Undo re-hides nuts that move revealed (no peeking via move+undo). Placement: Medium every 5th level from level 10 (hidden on half the bolts); Hard every 3rd level from level 6 (every bolt). Easy: none. Par assumes full information. Every mystery board verified solvable.
- TALL BOLTS (v2 rule 3): colours 4–18; nuts per colour 3–9; spare bolts ALWAYS >=2 (1 spare made all test boards unsolvable). Total nuts up to 90 on ladders, up to 108 on daily. Nuts must stay >=31px wide (easy taps). Max bolts on screen by height: 3–5 high -> 35; 6–7 -> 28; 8–10 -> 21; 12 -> 14. Board shapes per rung: packed, balanced, tall (plus daily shapes below). Layout engine auto-wraps bolts into rows to fit screen respecting these limits. Few stacks isn't automatically hard (4x9 = 26 moves); Hard tall levels use >=8 stacks. Reference measured shapes (2 spares): 4x9=36 nuts/26 moves, 6x9=54/45, 8x9=72/62, 10x9=90/81.
- Controls in play: Undo (unlimited, removes move from count, restores hidden), Hint (badge shows left), Restart, Extra bolt (free spare added, badge shows how many left; default 2 per level — tunable). No timer. No penalties.
- No-moves detection: when no legal move exists, show "No moves left" overlay automatically: Undo / use a free bolt / Restart.
